# Per-file mwccarm versions.
#
# The whole ROM builds byte-exactly with a single compiler, 1.2/b56 (build 56,
# Runtime Built 2004-09-16), which is what tools/configure.py now defaults to.
# All 1,536 matched units reproduce the digest `8d555a80...` under it with no
# per-file overrides, so the 72 `1.2/b56` entries that used to be listed here
# were an artefact of the old sp2 default and have been removed.
#
# This file stays as the escape hatch for a unit that genuine evidence shows was
# built by a different pre-existing build. An entry needs the full ROM digest to
# still match, and the tag must exist under tools/mwccarm/<tag>/mwccarm.exe.
#
# Format: <source path> = <version tag>
